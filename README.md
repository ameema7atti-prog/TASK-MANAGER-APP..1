# Task Manager Application 📋

A full-stack Task Manager web application built for **Task 3 (Project 1)** of the **Syntecxhub Web Development Internship**. This application allows users to securely authenticate, manage their tasks, and perform complete CRUD (Create, Read, Update, Delete) operations in a responsive interface[cite: 41].

## 🚀 Features
* **User Authentication:** Secure login and user management system[cite: 41].
* **Task Management (CRUD):** Create new tasks, read existing lists, update details or completion status, and delete outdated tasks[cite: 41].
* **Interactive UI:** Clean, modern dashboard interface built with React[cite: 41].
* **Full-Stack Architecture:** Designed for a React frontend connected to a Node.js and Express backend, with MongoDB data persistence[cite: 41].

## 🛠️ Tech Stack
* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3[cite: 41]
* **Backend:** Node.js, Express.js[cite: 41]
* **Database:** MongoDB[cite: 41]
